- 💼 Working at **Safran** on container platforms and observability solutions

- 📈 Building monitoring and logging capabilities with **Prometheus, Grafana, and Loki**
- 🔎 Integrating **Node Exporter** and **Blackbox Exporter** for infrastructure and endpoint monitoring

### Agentic Operations — AI-assisted Root Cause Analysis

</div>

I'm working on an Agentic Ops solution intended to help investigate operational issues and reduce repetitive toil. The approach brings together observability data, tool calling, and an AI agent workflow to support root cause analysis.

- 📊 **Signals:** Prometheus metrics, Grafana dashboards, Loki logs, and exporter data
- 🧠 **Agent workflow:** AWS AgentCore with a custom agent/model workflow using Opus 5.5
- 🔧 **Tools:** Harness and tool calling to gather relevant operational context
- 🎯 **Goal:** Help streamline investigations, surface useful findings, and reduce manual toil

> This is a work in progress; the description is intentionally high-level and does not include internal systems or sensitive implementation details.
